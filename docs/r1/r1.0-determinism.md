# R1.0a — Java 引擎的逐次确定性

> 任务：`docs/rewrite-plan-r1-r5.md` §4.1 R1.0a。
> 为什么必须先做：§3.1.3 的浮点容差在不知道抖动范围前无法定死；
> §3.1.4 的崩溃策略也依赖「同一用例重复计算是否一致」。

---

## 1. 方法

给 harness 加了 `--repeat N`（`tools/golden/src/net/ncplanner/plannerator/tools/GoldenGen.java`）：

对每个用例，在**同一个对象**上重复 `cub.clearCaches(); cub.recalculate();`，
用反射取全部数值字段（含 private），与第一次逐字段比较：

- 相等判定用 `Double.compare == 0`（`NaN` 与 `NaN` 视为相等）；
- 不相等时打印 `NON-REPEATABLE`，并给出两者的 **float ULP 距离**；
- 结束时输出「重复次数 / 有差异的用例数 / 最大 ULP 距离 / 发生变动的字段」。

在同一个对象上重复计算是刻意的：它同时检验 `recalculate()` 是否把
`hasPropogated`、`moderatorLines`、`wasActive`、簇列表、`offOutput` 等状态**干净地重置**。

## 2. 结果（实测）

```text
java ... GoldenGen --type sfr --cases 400 --seed 20260101 --min-size 3 --max-size 14 --repeat 10

--- repeatability (R1.0a: 10 evaluations per case) ---
re-evaluations  : 3429
differing cases : 0
max float ulps  : 0
result          : every numeric field is bit-for-bit identical
```

（400 例中 171 例是当时仍会 NPE 的用例，故重复次数为 3429 = 400×9 − 171×1。）

跨进程/跨运行同样一致：v2 与 v3 两次独立全量生成（各 5000 例）的 `editor` 与
`error` 字段逐条相同（见 `docs/r1/r1.0-dataset-naming.md` §3）。

## 3. 对容差的结论

| 项 | 结论 |
|---|---|
| 是否存在抖动 | **没有**。同一份源码 + 同一 JDK 下，所有数值字段逐位可复现 |
| §3.1.3 容差 | 保留「整数精确 + 浮点相对 1e-5」，但这是**保险**而非必需：TS 内核实测在 9,723 条记录上逐位一致 |
| 若换 JDK/平台 | 需要重跑本测量。`Math.sin` / `Math.exp` 等 `StrictMath` 之外的实现允许 1 ULP 级差异；这也是保留 1e-5 的实际理由 |
| 崩溃策略（§3.1.4） | 与确定性无关，但对拍前先跑一次即可确认没有「随机崩溃」 |

## 4. 复现

```powershell
pwsh -File tools/golden/golden.ps1 -Type sfr -Cases 400 -Seed 20260101 -MinSize 3 -MaxSize 14 `
     -Out "$env:TEMP\sfr-repeat.jsonl" -SkipCompile
# 注意：golden.ps1 未透传 --repeat，直接调用 java 更省事：
$jars  = Get-ChildItem libraries -Filter *.jar -File | Where-Object { $_.Name -notlike 'lwjgl*' -and $_.Name -ne 'joml-1.10.5.jar' }
$jars += Get-ChildItem libraries\DizzyEngine -Filter *.jar -File | Where-Object { $_.Name -notlike '*-sources.jar' -and $_.Name -notlike '*-javadoc.jar' }
$cp = @('tools\golden\build\classes','tools\golden\build\tools','src') + ($jars | ForEach-Object { $_.FullName })
java -cp ($cp -join ';') net.ncplanner.plannerator.tools.GoldenGen --type sfr --cases 400 --seed 20260101 --repeat 10 --out "$env:TEMP\sfr-repeat.jsonl"
```
